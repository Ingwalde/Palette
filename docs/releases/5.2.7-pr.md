# Palette 5.2.7: improve discovery, account saving and mobile interactions

Palette discovery and detail actions were difficult to use on small screens, and guest
favorites obscured the requirement to save palettes to an account. This release makes
saving explicit, simplifies palette cards and groups secondary actions.

## Changes

- Redesign palette cards and shorten the editorial hero while preserving randomized artwork.
- Require an account for Save and resume one requested save after authentication.
- Add exact color-count filtering (1–8), predictable tags and URL/back-navigation state.
- Preserve the selected palette when opening export and improve Favorites states.
- Improve mobile navigation, responsive search hints, theme readability, color-vision
  selection and viewport-safe Copy/More menus.
- Animate incoming pages and menu opening/closing; respect reduced-motion preferences.
- Update release notes, version strings and API documentation.
